= game-of-life-wgpu

This is an implementation of John Conway's game of life in rust. It uses the wgpu crate to compute all cells in parallel. There is no editor built-in, but you can load external pbm images.


video::https://codeberg.org/ThomasOniki/game-of-life-wgpu/raw/branch/main/images/breeder.mp4[]

= Building

cargo build --release

= Usage

game-of-life-wgpu <path-to-pbm>
